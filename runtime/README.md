## 실행과 범위

기존 v21과 Final calibration reference는 변경하지 않았다. 기본 `EVIDENCE_PRACTICE_HEADS=1`은 검토한 공개 보정과 기존 CPI수치 모델을 유지한다. `EVIDENCE_PRACTICE_HEADS=0`은 실험용 비교 경로로, 공개 보정으로 모델 응답을 가리는 일을 없앤다. 모든 실제 입력·인용은 task와 공식 frozen corpus의 cutoff·엔터티 연결·원래 구간을 따른다. 추가 신경망 모델이나 외부 추론 자료는 없다.

일반 House응답의 `mechanism`, `uncertainty`, 선택적인 `premise_quote`는 숫자 예측과 같은 응답에서 나온다. 짧은 사실 인용은 원문과 정확히 같고 완전한 문장/행의 경계를 만족해야 한다. 이 검사는 의미 적합성이나 예측 지지를 보장하지 않는다. production판정과 공식 R은 별도로 미측정이다.

길이 제한 때문에 선택적인 이유가 빠질 수 있다. 숫자 표현의 조건부12자리 반올림도 정답 기반 개선이 아니라 전달상의 tradeoff다. 로컬 보정·기존 결정식·fallback은 반올림하지 않으며, 변경량은 일반적으로 원래 절댓값의5e-12 이하(또는 float의1ULP)다. private naive오차가 정확히0인 예외에서는 아주 작은 숫자 변화도 Q에 영향을 줄 수 있으므로 성능 보장으로 부르지 않는다.
